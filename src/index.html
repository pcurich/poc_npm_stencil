Eventos disponibles (emitted events)

Lista de eventos que el componente puede emitir. Cada evento incluye nombre, tipo del payload, descripción, valores posibles y un ejemplo.

Evento Tipo (payload) Descripción Valores posibles Ejemplo
saveMockSchemaEvent MockSchema Emitido al guardar la metadata/configuración del mock desde la pestaña Mock (sin el cuerpo). Objeto con campos: nameMock, url, httpMethod, httpCodeResponseValue, serviceCode?, delayMs?, headers? 
{
  "nameMock": "demo-mock",
  "url": "/api/demo",
  "httpMethod": "GET",
  "httpCodeResponseValue": 200,
  "serviceCode": "svc-demo",
  "delayMs": 0,
  "headers": { "Authorization": "Bearer ..." }
}
saveMockBodyEvent MockBody Emitido al guardar el cuerpo/respuesta desde la pestaña Body. Contiene el JSON/texto que debe devolver el mock. Objeto con responseBody: string (JSON string o texto) 
{ "responseBody": "{\"ok\":true}" }
saveHeadersEvent Record<string,string> Emitido cuando el usuario guarda/actualiza las cabeceras en el editor de Headers. Objeto clave/valor con las cabeceras { "Authorization": "Bearer abc" }
loadContextEvent number Emitido para solicitar al host que cargue un contexto/registro por su ID (pestaña Load). ID numérico (enteros positivos) 42
deleteContextEvent number Emitido para solicitar al host que elimine un contexto/registro por su ID (pestaña Load). ID numérico (enteros positivos) 42
contextTypeChangeEvent ContextOption Emitido cuando el usuario cambia el tipo de contexto (select). Incluye el objeto ContextOption seleccionado. { id:number, value:string, useMock?:boolean } { id:3, value: 'Usar Data', useMock: true }
reloadEvent void Emitido para solicitar al host que realice una recarga/control externo (sin payload). Sin payload no payload

Nota: pasar objetos complejos como headers se hace mejor con asignación por propiedad en JS (element.headers = {...}) en vez de atributos HTML.

Demo interactiva

Usa los controles para configurar el componente y observa la consola integrada donde se mostrarán los eventos emitidos.

Configurar props (por sección)

Cada sección del componente (Context, Load, Mock, Headers, Body, Backup) expone props y emite eventos. Usa las pestañas a la izquierda para navegar entre secciones.

Context
Proporciona un array JSON de ContextOption para asignarlo a la propiedad contextOptions del componente.
Eventos (escuchados): contextTypeChangeEvent
Load
Eventos (emitidos por el componente): loadContextEvent
Mock
Eventos (emitidos por el componente): saveMockSchemaEvent
Headers
Eventos (emitidos por el componente): saveHeadersEvent
Body
Eventos (emitidos por el componente): saveMockBodyEvent
Backup
La pestaña Backup del componente permite exportar la configuración actual a un archivo JSON y volver a importarla. En la demo puedes abrir la pestaña del componente o disparar las acciones desde aquí.
Nota: la importación abrirá el diálogo de selección de archivo del componente (shadow DOM).

Explicación: "Aplicar como atributo" usa setAttribute (strings), "Aplicar como propiedad" asigna directamente la propiedad JS del elemento (permite pasar objetos).

Consola (event listener)

Casos de uso

1) Caso básico

Escenario: un mock sencillo que responde 200 con un body estático.

// Código conceptual (usando propiedad JS)
const el = document.createElement('mock-workbench');
el.name = 'simple-mock';
el.url = '/api/simple';
el.httpMethod = 'GET';
el.httpCodeResponseValue = 200;
el.responseBody = '{"ok":true, "msg":"OK"}';
document.body.appendChild(el);

// Escuchar eventos
el.addEventListener('saveMockSchemaEvent', e => console.log('Saved schema', e.detail));
el.addEventListener('saveMockBodyEvent', e => console.log('Saved body', e.detail));
